# 40 Days of JavaScript - by Tapascript

A collection of daily JavaScript tasks from the 
[40 Days of JavaScript](https://www.youtube.com/@tapasadhikary) 
course by **Tapas Adhikary (tapascript)** on YouTube.

## What is this?
Tapas Adhikary runs a free 40-day JS challenge on YouTube where each day 
covers a new JavaScript concept along with a hands-on task. This repo 
contains my solutions and practice files for each day.

## Topics Covered
- JavaScript fundamentals
- Functions, arrays, objects
- DOM manipulation
- ES6+ features
- And more...
